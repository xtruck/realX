# realX audit, 2026-10-21 (on `photoreal-integration`)

Method: ECC `production-audit` lens adapted to a local tool (realX is not deployed); evidence gathered by running things, not from README claims.
REA (the reverse-engineering MCP) was used to capture the live face-mesh page for the visual checks below.

## Score

**Launchable with caveats for a local, single-user tool: 72/100.** Capped below 85 because the four photorealism changes were never seen on a real
webcam and the 20 fps gate with them is only measured on a non-representative run.

## Owner decisions (not delegated)

* **No `LICENSE` file.** Choose one. The project rules say dependencies are permissive-only; this audit did not re-check that. Nothing is assumed.
* **Real-webcam validation** of the four photorealism branches (`photoreal-neck`, `-hair-halo`, `-body-seams`, `-cheap-edges`, merged in `photoreal-integration`):
  the neck/collar stair is ambiguous on the astronaut clip (black collar vs shadow); it needs the owner's own neck and light.
* **Pull requests / merge to `main`:** nothing has been merged; all work is on branches.
* **Glasses photo (gap #5):** needs a glasses-free photo.
